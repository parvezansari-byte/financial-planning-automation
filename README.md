# 🚀 Freedom ULTRA PRO MFD CRM

A premium **Streamlit-based Financial Planning + MFD CRM + Client Conversion Dashboard** built for **Mutual Fund Distributors (MFDs), Advisors, and Relationship Managers**.

## ✨ Features

- 🔐 Advisor login screen
- 📞 Lead CRM (Add / Search / Filter / Delete)
- 👥 Client CRM (Add / Search / Delete)
- 📈 SIP Proposal Calculator
- 🏖 Retirement Planning Engine
- 🛡 Protection Gap Analysis (Life + Health)
- 🏦 EMI + Tax Review
- 🏆 RM Leaderboard
- 📂 CSV Upload Center
- 📊 MIS Reports Download Center
- 🧾 Final Business Summary Dashboard
- 🌙 Premium dark theme UI
- ☁️ Streamlit Cloud safe
- 📦 Single-file `app.py`

## 🛠 Tech Stack

- Python
- Streamlit
